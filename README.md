# istile-tp-m1m2-FOAPA-Gianny
FOAPA GIANNY ROBERT

Mini-annuaire ISTILE réalisé en HTML, CSS et JavaScript natifs. Le projet couvre les données JSON, les transformations de tableaux et les appels asynchrones à l’API DummyJSON.

## Lancer le projet

```bash
npm start
```

Le programme affiche les traitements des données locales et teste trois scénarios d’API : chargement réussi, utilisateur inexistant et erreur réseau.
